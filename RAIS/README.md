# RAIS earnings percentiles

This module builds the RAIS descriptive evidence used in the first empirical part of the project.
It is separated from the PNADC module because the empirical object is different: RAIS is used to
describe the formal labor earnings distribution, while PNADC is used to estimate labor-market
transitions across employment, unemployment, and non-participation.

## Output object

The baseline sample follows the current empirical design:

- Men aged 25-55.
- Formal RAIS employment links.
- Baseline income variable: `remuneracao_media_sm`.
- Unit of observation in the current streaming pipeline: `vinculo_ano`.
- Main percentiles: P20, P50, P90, and P95.
- Additional stored percentiles: P01, P05, P10, P25, P75, and P99.

Important interpretation note: the baseline income variable is average remuneration in multiples
of the minimum wage. Therefore, declines in the indexed percentile figures indicate a reduction in
the number of minimum wages, not necessarily a fall in real earnings.

## Folder structure

- `scripts/08_pipeline_leve_percentis_streaming.R`: downloads/reads RAIS files one year/block at a time and computes annual percentiles without storing the full microdata.
- `scripts/09_grafico_heathcote_streaming.R`: creates the Heathcote-style percentile figures from the percentile panel.
- `scripts/10_combinar_paineis_streaming.R`: combines available streaming percentile panels.
- `scripts/11_graphs.R`: creates percentile-ratio figures, especially P90/P50 and P50/P20.
- `raw/`: optional local cache for downloaded RAIS `.7z` files.
- `intermediate/`: checkpoints and processing logs.
- `final/`: final percentile panels and indexed panels.
- `figures/`: figures used in the written project.

Some older exploratory scripts live in `../scripts/`. The current RAIS module should rely primarily
on the scripts listed above.

## Requirements

Install the required R packages once:

```r
install.packages(c("data.table", "archive", "ggplot2"))
```

The streaming pipeline downloads RAIS files from the public MTE/RAIS FTP when local files are not
found. Network access is therefore required for full collection unless the files already exist in
`raw/`.

## Basic use

From this folder:

```bash
Rscript scripts/08_pipeline_leve_percentis_streaming.R 1994:2024
Rscript scripts/09_grafico_heathcote_streaming.R final/painel_percentis_streaming_remuneracao_media_sm_homens_25_55_1994_2024.csv
Rscript scripts/11_graphs.R
```

If the percentile panel already exists, you do not need to rerun the heavy RAIS processing. Run only
the graph scripts:

```bash
Rscript scripts/09_grafico_heathcote_streaming.R final/painel_percentis_streaming_remuneracao_media_sm_homens_25_55_1994_2024.csv
Rscript scripts/11_graphs.R
```

## Useful environment variables

- `RAIS_ANOS`: years to process if not supplied as a command argument. Default: `1994:2024`.
- `RAIS_UFS`: comma-separated UF list. Default: all UFs available in the script.
- `RAIS_RENDA_VAR`: income variable used for percentiles. Default: `remuneracao_media_sm`.
- `RAIS_RAW_DIR`: folder for local `.7z` files. Default: `raw`.
- `RAIS_BAIXAR_AUSENTES`: whether missing files should be downloaded. Default: `TRUE`.
- `RAIS_USAR_CACHE_RAW`: whether new downloads should be kept in `raw/`. Default: `FALSE`.
- `RAIS_MANTER_TEMP`: whether temporary extraction folders should be kept. Default: `FALSE`.
- `RAIS_ANO_BASE`: base year for indexed figures. Default: `1994`.
- `RAIS_PARTIAL_COVERAGE_FROM`: year from which figures shade partial coverage. Default: `2018`.

Examples:

```bash
RAIS_BAIXAR_AUSENTES=FALSE Rscript scripts/08_pipeline_leve_percentis_streaming.R 1994:2017
RAIS_RENDA_VAR=remuneracao_media_nom Rscript scripts/08_pipeline_leve_percentis_streaming.R 1994:2024
RAIS_ANO_BASE=1994 Rscript scripts/09_grafico_heathcote_streaming.R final/painel_percentis_streaming_remuneracao_media_sm_homens_25_55_1994_2024.csv
```

## Current data caveats

- The current baseline figures in the written project cover 1994-2022, not the full target period 1994-2024.
- Data from 2018 onward should be treated as partial until all regional RAIS blocks are successfully processed.
- The variable `remuneracao_media_sm` measures earnings in multiples of the minimum wage. It is useful for studying compression relative to the minimum wage, but it should not be interpreted as real earnings.
- A real-earnings version should use nominal remuneration deflated by IPCA/INPC, preferably after aggregating all links to the worker-year level.
- The current streaming pipeline stores `nivel_observacao = "vinculo_ano"`. For a worker-level distribution, the next improvement is to aggregate links by worker/year before calculating percentiles.

## Next improvements

Recommended extensions for the RAIS module:

1. Add a deflated-real-earnings pipeline using nominal remuneration and an official price index.
2. Add a worker-year aggregation step before computing percentiles.
3. Add public/private-sector filters and robustness outputs.
4. Complete or validate the post-2017 regional file processing before treating 2018-2024 as national coverage.
5. Keep the minimum-wage-multiple figures as a separate institutional/compression exercise rather than the main real-income figure.
